# HR Analytics Dashboard | Power BI

## Project Overview

Developed an interactive HR Analytics Dashboard in Power BI to analyze workforce trends and identify factors contributing to employee attrition. The project transforms raw HR data 
into actionable business insights through data preparation, data modeling, DAX calculations, and interactive visualizations.

## Objectives

- Analyze employee attrition across different workforce segments.
- Monitor key HR performance indicators (KPIs).
- Identify trends related to employee turnover.
- Support data-driven HR decision-making through interactive reporting.

## Dataset

- **Dataset:** HR_Data.xlsx
- **Domain:** Human Resources
- **Records:** 1,470 Employees

## Data Preparation

The dataset was prepared using Power Query before building the dashboard.

- Imported HR data into Power BI.
- Cleaned and transformed the dataset using Power Query.
- Corrected data types.
- Standardized inconsistent text values.
- Replaced incorrect values and handled data inconsistencies.
- Prepared the dataset for reporting and analysis.

## Data Modeling

Built an optimized data model by creating relationships between the following tables:

- HR_Data
- Departments
- Jobs
- Education

The model improves reporting performance and supports efficient filtering across the dashboard.

## DAX Measures

Created DAX measures to calculate key HR metrics, including:

- Employee Count
- Attrition Count
- Attrition Rate
- Average Age
- Average Salary
- Average Years at Company

## Dashboard Features

The interactive dashboard includes:

- KPI Cards
- Department Slicer
- Attrition by Gender
- Attrition by Education
- Attrition by Age Group
- Attrition by Salary Slab
- Attrition by Years at Company
- Attrition by Job Role
- Job Satisfaction Matrix

## Business Insights

- Calculated an overall employee attrition rate of approximately **16%**.
- Identified higher attrition among employees aged **26–35**.
- Observed higher employee turnover within lower salary groups.
- Compared attrition across departments, education fields, job roles, and years at the company.
- Developed an interactive dashboard that enables HR managers to monitor workforce metrics and support data-driven decision-making.
